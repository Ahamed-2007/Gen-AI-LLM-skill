🤖 Generative AI Projects

This repository contains my beginner-level Generative AI projects created while learning and experimenting with AI models and tools.

🚀 Projects
1. 🎨 Text-to-Image Generation

Generates images based on a text prompt using a Generative AI image model.

Input: Text prompt
Output: AI-generated image

Example:
A futuristic city at night with flying cars

2. 🖼️ Image Classification

Classifies an uploaded image into a specific category using a trained machine learning model.

Input: Image
Output: Predicted class with confidence percentage

Example:
Dog → 95%
Cat → 5%

The project also includes image-based prediction through a user-friendly interface.

3. ✍️ Text Generation

Generates text based on a user-provided prompt using a Hugging Face language model.

Input: Text prompt
Output: AI-generated text

Example:
Prompt: Hi, I love AI and ML
→ Generates a continuation based on the prompt.
